# MIRROR ME — публичная витрина проекта

[![Tests](https://github.com/JpegPolzovatelya/mirror-me-showcase/actions/workflows/tests.yml/badge.svg)](https://github.com/JpegPolzovatelya/mirror-me-showcase/actions/workflows/tests.yml)

Этот репозиторий содержит ограниченный набор исходного кода проекта MIRROR ME,
достаточный для технического ознакомления с прототипом. Полная платформа,
инфраструктура и рабочие данные намеренно не публикуются.

MIRROR ME — программный прототип для игровых и учебных сценариев с анализом
мимики, жестов и движений пользователя. Проект не является медицинской системой
и не выполняет диагностику.

## Что показано

### Распознавание эмоций

В каталоге `components/emotion-recognition` находятся перечень игровых классов
эмоций, конечный автомат короткой сессии и правила выбора модели. Прототип
использует пять классов: радость, удивление, грусть, злость и отвращение.

### Распознавание жестов

В каталоге `components/gesture-recognition` показана логика четырёх упражнений:
«Дай», «На», «Привет» и «Пока». Учитываются геометрия кисти, направление ладони
и движение во времени.

### Мультимодальное объединение

В каталоге `components/multimodal-fusion` находится ограниченная логика
объединения событий от нескольких модулей и формирования результата сессии.

### Другие части проекта

Полная система также включает веб-платформу, backend API, хранение обезличенных
профилей и сессий, прототипы компьютерного зрения и VR-сценарии. Эти части
подтверждаются отдельно демонстрационными материалами и не публикуются здесь
целиком.

Связанный модуль отчётов: [MIRROR ME Telegram Bot](https://github.com/JpegPolzovatelya/mirror-me-telegram-bot).

## Проверка

Требуется Node.js 20 или новее.

```bash
npm test
```

Тесты используют только синтетические координаты и программные события. Камера,
фотографии, биометрические данные, токены и сетевые сервисы для запуска тестов не
нужны.

## Границы публикации

В репозиторий не включены:

- веса моделей и сторонние runtime-файлы;
- исходники серверной инфраструктуры и закрытой платформы;
- адреса серверов, `.env`, ключи, токены и пароли;
- базы данных, персональные и биометрические данные;
- реальные результаты тестирования и внутренние документы;
- материалы других проектов.

Подробное описание состава приведено в [документе о границах витрины](docs/SCOPE.md).
